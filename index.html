Questions

What classmates and the course staff ask about the project. Read the source on GitHub

Where is the AI in this game?

In two places: five search algorithms find the path to the door, and the shades pick every move with a game-tree search.

Why does A* search open fewer cells than UCS?

It adds h(n), the Manhattan distance to the door. The guess never overestimates, so A* skips cells that lead away and still finds the cheapest path.

What does alpha-beta pruning change in the search?

Only the work: the same move as plain minimax, with the branches the opponent would never allow left out.

How do I run the game offline for a talk?

Run npm install and npm run build once, then npm run preview. npm test checks the algorithms on 40 random labyrinths.
